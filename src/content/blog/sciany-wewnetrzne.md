# Ściany Wewnętrzne w Domach z Płyt PIR — Kompletny Przewodnik 2026

*Porównanie systemów ścian wewnętrznych dla domów na szkieletcie stalowym z płyt warstwowych PIR. Które rozwiązanie wybrać?*

---

## Wprowadzenie

Ściany wewnętrzne w domach z płyt warstwowych PIR muszą spełniać wymagania:
- **Akustyczne** — izolacja dźwiękowa między pomieszczeniami
- **Konstrukcyjne** — przenoszenie obciążeń (jeśli nośne)
- **Estetyczne** — możliwość wykończenia
- **Ekonomiczne** — koszt wykonania

W tym przewodniku przeanalizujemy **5 najpopularniejszych systemów** ścian wewnętrznych i pomożemy Ci wybrać najlepsze rozwiązanie dla Twojego domu PIR.

---

## 1. Płyta Warstwowa PIR (Ściana działowa)

### Budowa:
```
┌─────────────────────────────────────┐
│ Okładzina blacha 0,5mm              │
├─────────────────────────────────────┤
│ Rdzeń PIR 40-80mm                   │
├─────────────────────────────────────┤
│ Okładzina blacha 0,5mm              │
└─────────────────────────────────────┘
```

### Zalety:
- ⚡ **Najszybszy montaż** — gotowe elementy
- 💰 **Najniższy koszt** — 80-120 zł/m²
- 🔇 **Dobra izolacja termiczna** — brak mostków
- 🧹 **Czysty montaż** — bez mokrych procesów

### Wady:
- 🔊 **Słaba izolacja akustyczna** — Rw = 25-30 dB
- 🔨 **Trudne wieszanie ciężkich elementów** — konieczne wzmocnienia
- 🎨 **Ograniczone wykończenie** — blacha wymaga okładziny
- 📏 **Ograniczone grubości** — min. 40mm

### Jak poprawić izolację akustyczną?

**Rozwiązanie 1: Dodatkowa warstwa G-K**
- Płyta PIR 60mm + 2x G-K 12,5mm + wełna 50mm
- → Rw = 45-50 dB (poprawa +20 dB!)

**Rozwiązanie 2: Dwie warstwy płyt**
- Płyta PIR 60mm + szczelina 20mm + płyta PIR 40mm
- → Rw = 35-40 dB

### Zastosowanie:
- Dzielące pomieszczenia nie wymagające ciszy
- Ściany magazynowe, gospodarcze
- Przegrody w halach przystosowane do mieszkalnictwa

## 2. Płyta G-K na Profilach Metalowych

### Budowa (standard):
```
┌─────────────────────────────────────┐
│ Płyta G-K 12,5mm                    │
├─────────────────────────────────────┤
│ Profil C 50/75/100mm                │
│ + wełna mineralna 50-100mm          │
├─────────────────────────────────────┤
│ Płyta G-K 12,5mm                    │
└─────────────────────────────────────┘
```

### Warianty:

| Wariant | Rw [dB] | Grubość | Zastosowanie |
|---------|---------|---------|--------------|
| 1x G-K + wełna 50mm | 35-40 dB | 75mm | Pomieszczenia ogólne |
| 2x G-K + wełna 50mm | 45-50 dB | 100mm | Sypialnie, biura |
| 2x G-K + wełna 100mm | 50-55 dB | 150mm | Pokoje dziecięce, gabinety |

### Zalety:
- 🔇 **Dobra izolacja akustyczna** — do 55 dB
- 🎨 **Łatwe wykończenie** — tynk, farba, tapeta
- 🔨 **Łatwe wieszanie** — kołki rozporowe standardowe
- 💡 **Instalacje wewnątrz** — puszki, przewody

### Wady:
- ⏱️ **Dłuższy montaż** — 2-3 dni
- 💧 **Wrażliwość na wilgoć** — wymaga zabezpieczenia
- 📉 **Mniejsza trwałość** — uszkodzenia mechaniczne

### Koszty materiałów:

| Element | Cena/jedn. | Na m² |
|---------|------------|-------|
| Profil CW 50 | 15 zł/szt | ~30 zł |
| Płyta G-K 12,5mm | 25 zł/szt | ~50 zł |
| Wełna 50mm | 20 zł/m² | 20 zł |
| Akcesoria | — | ~20 zł |
| **RAZEM** | — | **~120 zł/m²** |

- 🔨 **Łatwe wieszanie** — kołki standardowe

## 4. Beton Komórkowy (SUPOTHERM, SOLBET)

### Budowa:
```
┌─────────────────────────────────────┐
│ Bloczek beton komórkowy 100-175mm   │
│ + klej cienkowarstwowy              │
│ + gładź + farba                     │
└─────────────────────────────────────┘
```

### Zalety:
- ⚡ **Szybki montaż** — duże formaty
- 🔇 **Dobra izolacja akustyczna** — 35-42 dB
- 🌡️ **Izolacja termiczna** — λ = 0,09-0,12
- ✂️ **Łatwa obróbka** — piła, dłuto
- 🎨 **Łatwe wykończenie** — gładź bez tynku

### Wady:
- 💧 **Wrażliwość na wilgoć** — wymaga zabezpieczenia
- 🔨 **Trudne wieszanie ciężkie** — specjalne kołki
- 📉 **Mniejsza wytrzymałość** — nie dla ścian nośnych wysokich

### Wymiary standardowe:

| Typ | Wymiary | Sztuk/m² |
|-----|---------|----------|
| SUPOTHERM 10 | 600x240x100 | ~7 |
| SUPOTHERM 17,5 | 600x240x175 | ~7 |

- 💪 **Największa sztywność** — stabilność

### Wady:

- 💰 **Najwyższy koszt** — 180-250 zł/m²
- 🏗️ **Wymaga zbrojenia** — pręty, strzemiona
- 💧 **Mokre procesy** — betonowanie

## Wymagania Akustyczne (Polska)

### Norma PN-B-02151-2:

| Pomieszczenie | Wymagane Rw |
|---------------|-------------|
| Ściana między pokojami | min. 40 dB |
| Ściana do łazienki | min. 45 dB |
| Ściana do klatki schodowej | min. 50 dB |
| Ściana między mieszkaniami | min. 52 dB |

### Dla domów jednorodzinnych:
- **Zalecane:** Rw ≥ 40 dB dla ścian między sypialniami
- **Optymalne:** Rw ≥ 45 dB dla ścian do łazienek

## Ważne: Odkształcenia Termiczne

| Materiał | Wsp. rozszerzalności | Przy ΔT=20°C na 3m |
|----------|---------------------|-------------------|
| Stal | 12×10⁻⁶ /K | 0,72 mm |
| Beton | 10×10⁻⁶ /K | 0,60 mm |
| Cegła | 5×10⁻⁶ /K | 0,30 mm |
| **PIR** | 30-50×10⁻⁶ /K | **1,8-3,0 mm** |

⚠️ **Wniosek:** Płyty PIR wymagają dylatacji! W ścianach działowych z PIR musisz uwzględnić szczeliny dylatacyjne co 3-4 metry.

## Rekomendacje dla Domów PIR

### ✅ Standardowy dom (ekonomiczny):
- **Ściany działowe:** Płyta PIR 60mm
- **Ściany do łazienek:** G-K 2x12,5mm + wełna 50mm
- **Koszt:** ~100 zł/m² średnio

### ✅ Dom premium (cisza):
- **Ściany działowe:** G-K 2x12,5mm + wełna 75mm
- **Ściany do łazienek:** Bloczek 12cm lub beton komórkowy 17,5cm
- **Koszt:** ~150 zł/m² średnio

### ✅ Dom pasywny (termo):
- **Ściany działowe:** Płyta PIR 80mm + dodatkowa izolacja
- **Uwaga:** Wymaga uwzględnienia dylatacji termicznych

## Podsumowanie

Wybór ściany wewnętrznej w domu PIR zależy od Twoich priorytetów:

| Priorytet | Rekomendowane rozwiązanie |
|-----------|---------------------------|
| **Najniższy koszt** | Płyta PIR 60mm |
| **Najlepsza cisza** | Płyta G-K 2x12,5mm + wełna 100mm |
| **Najszybszy montaż** | Płyta PIR |
| **Tradycyjne wykończenie** | Bloczek ceramiczny |
| **Najtrwalsze** | Bloczek ceramiczny / pustak szalunkowy |

Pamiętaj o **dylatacjach** przy ścianach z płyt PIR i **dodatkowej izolacji akustycznej** tam, gdzie potrzebujesz ciszy (sypialnie, pokoje dziecięce).
