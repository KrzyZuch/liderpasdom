# Akustyka w Domach PIR 2026

## Wprowadzenie

Domy szkieletowe PIR często kojarzą się z problemami akustycznymi. Jednak przy odpowiednim projektowaniu i wykonaniu, mogą osiągnąć doskonałą izolacyjność akustyczną na poziomie R'A1 > 50 dB.

## 1. Podstawowe Parametry Akustyczne

### Wymagania normowe (2026)
| Element | Wymaganie R'A1 |
|---------|----------------|
| Ściana między mieszkaniami | ≥ 50 dB |
| Ściana zewnętrzna | ≥ 35 dB |
| Strop | ≥ 50 dB |
| Drzwi wejściowe | ≥ 30 dB |

### Współczynniki izolacyjności
- **Rw** - wskaźnik izolacyjności akustycznej
- **C, Ctr** - współczynniki korekcyjne

## 2. Konstrukcja Ścian Akustycznych

### Ściana wielowarstwowa (rekomendowana)
```
Płyta gipsowa 12,5mm
Pusta przestrzeń 50mm + wełna
Płyta PIR 20cm
Pusta przestrzeń 50mm + wełna  
Płyta gipsowa 12,5mm
```
**Wynik:** Rw ≈ 55-60 dB

## 3. Eliminacja Mostków Akustycznych

### Rozwiązania
- Elastyczne połączenia konstrukcji
- Taśmy akustyczne na stykach
- Izolacja wełną mineralną w szkieletcie

## 4. Izolacja Podłóg

### Systemy
| System | Izolacyjność |
|--------|--------------|
| Płyta PIR 30mm + jastrych | Rw ~ 55 dB |
| Płyta PIR 40mm + płyta OSB | Rw ~ 50 dB |

## 5. Okna i Drzwi

### Okna
- Standard 2026: min. 3 szyby
- Izolacyjność: Rw 32-38 dB

### Drzwi
- Drzwi akustyczne: Rw 35-45 dB
- Uszczelki na całym obwodzie

## 6. Koszty Dodatkowe

| Rozwiązanie | Koszt |
|-------------|-------|
| Podwójny szkielet | 150-200 zł/m² |
| Okna akustyczne | 200-400 zł/szt. |
| Drzwi akustyczne | 800-1500 zł/szt. |

## Podsumowanie

Domy PIR mogą osiągnąć izolacyjność akustyczną porównywalną z domami murowanymi. Kluczowa jest konstrukcja wielowarstwowa i eliminacja mostków akustycznych.
